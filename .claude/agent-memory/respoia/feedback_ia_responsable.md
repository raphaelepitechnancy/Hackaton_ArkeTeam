Toujours citer la source officielle dans les encarts d'explication (lien cliquable + mention "les sources officielles font foi").

**Why:** Mission explicabilité du responsable IA — le jury évalue l'utilité et la clarté, pas la sophistication. Une explication sans source n'est pas fiable.

**How to apply:** Chaque bloc explication doit exposer `source` + `lien_officiel`. Ne jamais afficher une explication générée sans fallback vers le texte statique. Rappeler systématiquement que les sources officielles font foi.
