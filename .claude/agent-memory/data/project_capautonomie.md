CapAutonomie est une application d'aide administrative pour jeunes adultes 18-25 ans (étudiant, alternant, premier emploi, étudiant étranger). Hackathon avec deadlines strictes en blocs.

**Why:** Simplifier l'accès aux démarches administratives pour éviter la perte de droits chez les jeunes entrant dans la vie autonome.

**How to apply:** Les données doivent rester en langage simple (zéro jargon), sources 100% officielles (Service-Public.fr, CAF.fr, Ameli.fr, impots.gouv.fr, etudiant.gouv.fr), et chaque démarche doit avoir un lien fonctionnel.

Fichier principal : `/home/lucca/TEK2/HACKATON/hackatton_arke/data/demarches.json`
- 10 démarches couvertes
- Structure JSON validée (Python json.load)
- 8 démarches P1 (urgent), 2 démarches P2 (important)
- Catégories : logement, aides, sante, impots, transport, autre
- Page sources incluse dans le JSON (clé "page_sources")
- BLOC 1 deadline : 09h30 - livré
