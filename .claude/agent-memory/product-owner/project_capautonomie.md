Hackathon "IA et relation usager dans les services publics" — Telecom Nancy, restitution 2026-05-20 fin de journée.

**Projet CapAutonomie** : application web guidant les 18-25 ans (étudiants, alternants, jeunes actifs) dans leurs 5 premières démarches administratives lors d'un premier appartement.

**Cas démo** : étudiant 20 ans, premier appartement à Nancy.

**5 démarches ciblées** : CAF/APL, assurance habitation, Sécurité sociale/Ameli, impôts, transport étudiant.

**Équipe (5 personnes)** :
- Frontend
- UX/UI
- Data
- IA/Logique
- Pitch/Oral

**MVP 4 pages** :
1. Landing page (< 30 secondes pour comprendre)
2. Questionnaire (5 questions, branching statut + logement)
3. Résultats personnalisés (démarches + docs + priorités + liens officiels)
4. Page Sources/Transparence (IA responsable)

**Fonctionnalités clés** :
- Questionnaire intelligent (règles de matching)
- Affichage démarches avec documents requis, priorités, liens officiels
- Bouton "explique-moi simplement" (reformulation IA)
- Section IA responsable / transparence

**Hors scope** : auth, compte, vraie DB, calcul d'éligibilité officiel, chatbot généraliste.

**Data** : JSON local, sources officielles (Service-Public.fr, CAF.fr, Ameli.fr, impots.gouv.fr, etudiant.gouv.fr), mention "à vérifier sur site officiel".

**Grille d'évaluation hackathon** :
- Qualité technique du prototype : 60 %
- Pertinence relation usager : 20 %
- Contraintes non fonctionnelles (sécurité, droit, éthique, environnement) : 20 %

**Restitution** : 10 min max — 2 min problème usager / 4 min données + technique / 2 min démo / 2 min contraintes responsables.

**Jury** : grand public non technique. Le jury privilégie la clarté à la quantité. Évaluation sur IA utile, compréhensible et responsable — pas l'effet "waouh".

**Why:** Hackathon court (1 journée), deadline fixe fin de journée, public non technique, évaluation sur cohérence et responsabilité IA plus que complexité.

**How to apply:** Toutes recommandations doivent maximiser la crédibilité technique + l'explication des choix responsables + la clarté de la démo en 2 minutes, pas la richesse fonctionnelle.
